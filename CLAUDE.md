# CLAUDE.md

Generated artifacts — never hand-edit; change the source and regenerate:
- `plugins/proofpunk/themes/{omp,opencode,hyper}/` ← edit
  `plugins/proofpunk/themes/palettes.json`, run `python3 tools/generate-themes.py`
- `docs/*.html` ← generated by `tools/build-site.py`; edit the markdown
  sources it reads, not the HTML

Deliberate layout — do not "fix":
- Skills cite shared doctrine as `../../references/X` on purpose.
  `tools/proofpunk-install.sh` rewrites citations to self-contained
  copies at install time; localizing paths in-repo breaks the plugin tree.

Verification before claiming a skills/hooks/installer change done:
- `bash tools/test-hooks.sh`
- `bash tools/dry-run-install.sh`
- `python3 tools/verify-orchestration.py`
- Capture all three outputs under `evidence/<release>/` — naming
  convention in `evidence/v2.0.1-release/`

Known recurring failure — sweep after changing the skill set or version:
- stale skill/command counts and version strings in
  `plugins/proofpunk/package.json`, `README.md`, `tools/INSTALL.md`, and
  the page sources inside `tools/build-site.py` (see commits 2953547, 7958498)
