What the docs DON'T answer (recorded, not assumed)

  • No deterministic skill-match metric anywhere — auto-invocation is model judgment over the description. Specific descriptions are the only lever.
  • CLAUDE.md conflict precedence is explicitly undefined.
  • Hook execution is guaranteed; model compliance with soft context is not — hard guarantees live only in blocking decisions (PreToolUse deny, Stop block).
